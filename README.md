Forecast, for every trophy of Grand Theft Auto VI on PlayStation 5, the percent of the players Exophase tracks for the game who will have earned it at 2026-11-26T00:00:00Z, a week after launch — as five quantiles a trophy, from the earn rates the house recorded up to the deadline.  The entry adds a calibrated refresh term to the persistence baseline's spread, so the forecast carries a band wide enough to cover a step change like Exophase's first refresh of the game's counts on launch night, without widening on a trophy that does not move.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
